# ishul.org — landing page

Static landing page for [iShul](https://github.com/dani2906/ishul), served via GitHub Pages at https://ishul.org.

- `index.html` — the entire site (self-contained HTML/CSS, no build step)
- `favicon.svg` — site icon
- `CNAME` — custom domain for GitHub Pages

## Editing

Edit `index.html` and push to `main`. GitHub Pages redeploys automatically within a minute or two.
